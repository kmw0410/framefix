# FrameFix
Chrome 전용 YouTube 화질 고정 확장프로그램

한국어 | [English](./README.md)

## 기능

- 재생 화질 변경 (144p ~ 4320p 지원)
- 일반 동영상과 Shorts에서 화질 적용
- 향상된 비트레이트 ON/OFF 토글 지원 (기본값 OFF, **YouTube Premium 계정 필요**)
- 자동(시스템), 라이트, 다크모드 지원
- 한국어/영어 지원
- 설정 자동 저장 및 내보내기/불러오기 지원

## 설치

해당 확장 프로그램은 Chrome 웹 스토어에 등록되어 있지 않습니다.

1. GitHub **Releases**에서 `framefix-<버전>-chrome.zip`을 다운로드하고 압축을 풉니다.
2. Chrome에서 `chrome://extensions`를 열고 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램 로드**를 클릭하고 `manifest.json`이 들어 있는 압축 해제 폴더를 선택합니다.
4. 설치가 완료되면 열려 있는 YouTube 페이지를 새로고침합니다.

## 디렉토리 구조

- `src/popup`: 설정 UI와 시스템 색상 변화에 반응하는 CSS 테마
- `src/content`: 확장 저장소와 페이지 사이의 설정 전달
- `src/player`: 플레이어 제어 및 재시도
- `src/shared`: 설정 검증과 화질 선택 정책
- `i18n/ko`, `i18n/en`: 번역 원본 (빌드 시 `_locales`로 복사)
- `manifests`: 브라우저별 설정
- `tests`: 화질 정책과 설정 검증

## 설정 백업

팝업 하단의 **설정 내보내기**로 `framefix-settings.json`을 저장하고, **설정 가져오기**로 Chrome 브라우저 또는 기기 사이에서 설정을 옮길 수 있습니다. 파일에는 `app: "framefix"`, 형식 `version: 2`, ON/OFF·화질·비트레이트·테마·언어 설정이 들어갑니다. 가져오기는 기존 설정 전체를 교체하며 저장 성공 후 즉시 반영됩니다. 잘못된 형식·값, 미지원 버전, 64KB 초과 파일은 기존 설정을 변경하지 않습니다. 추가 권한이나 외부 전송은 없습니다.

## 화면 언어

팝업의 언어 선택에서 **자동 / 한국어 / English**를 선택할 수 있습니다. 자동은 브라우저 언어를 따르며 한국어 이외의 언어는 영어로 표시합니다. 변경은 팝업 전체에 즉시 반영되고 로컬에 저장됩니다. JSON 백업에도 언어가 포함되며, 언어 필드가 없는 기존 백업은 자동으로 가져옵니다. 확장 관리 화면의 이름과 설명은 브라우저의 기본 다국어 규칙을 따릅니다.

기존 저장소 및 버전 1 백업의 `quality: "auto"`는 OFF + 1080p로 이전됩니다. 이전 화질을 복원할 수 없는 경우 기본 1080p를 사용하며, 다른 화질의 기존 설정은 ON 상태로 유지됩니다. 버전 1 백업도 계속 가져올 수 있습니다.

## CHZZK

팝업의 YouTube / CHZZK 버튼으로 사이트별 설정을 선택합니다. CHZZK는 1080p 이하에서 제공되는 최고 화질을 선택합니다. CHZZK ON/OFF는 YouTube와 독립적입니다. 볼륨 100% 옵션은 재생 시작 시 적용하며, 음소거 상태와 이후 사용자의 볼륨 조절은 유지합니다. 마지막으로 선택한 사이트 탭을 기억합니다.

CHZZK는 플레이어의 화질 메뉴 DOM을 사용하는 방식으로, 사이트 변경이나 메뉴가 생성되지 않은 상태에서는 적용되지 않을 수 있습니다. 라이브·다시보기 실사이트 검증이 필요합니다. 백업 v3에 CHZZK 설정이 포함되며 기존 v1/v2도 가져올 수 있습니다.

FrameFix는 독립적인 서드파티 확장 프로그램이며, YouTube·Google 및 CHZZK·NAVER와 관련이 없습니다.
